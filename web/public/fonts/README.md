# Bundled fonts

- `maple-mono-cn/` contains Maple Mono CN, used for terminal output and other monospace text. Source: <https://github.com/subframe7536/maple-font>
- `noto-sans-sc/` contains Noto Sans SC, used for Simplified Chinese interface text. Source: <https://github.com/notofonts/noto-cjk>

Both font families are distributed under the SIL Open Font License 1.1. See `OFL-1.1.txt` in this directory. The proprietary Arial files from the local design-material folder are deliberately not bundled; the UI uses the operating system's Arial installation when available.
