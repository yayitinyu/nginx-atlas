# Bundled fonts

- `maple-mono-cn/` contains Maple Mono CN, used for terminal output and other monospace text. Source: <https://github.com/subframe7536/maple-font>
- `noto-sans-sc/` contains Noto Sans SC, used for Simplified Chinese interface text. Source: <https://github.com/notofonts/noto-cjk>
- `geist/` contains the Latin variable roman and italic subsets of Geist, used for Western interface text. Source: <https://fonts.google.com/specimen/Geist>
- `orbitron/` contains the Latin variable subset of Orbitron, used only for the NGINX ATLAS wordmark. Source: <https://fonts.google.com/specimen/Orbitron>

These font families are distributed under the SIL Open Font License 1.1. See `OFL-1.1.txt` in this directory. The proprietary Arial files from the local design-material folder are deliberately not bundled.
